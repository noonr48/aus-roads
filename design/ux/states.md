# Map search — tier S state row

Existing overlay; no new flow. Convention: standard top search input and a primary Retry button for failed work. Input is never discarded by an error.

## Existing app state shelf — 2026-10-06

This extends the existing Map / Explore (`nearby`) / Pins / Settings app, not its flows. Keyword discovery and deterministic suggestions use local explicit interests/visits; search, GPS, map selection and route-start do not infer visits. Preserve map, offline behavior, navigation, saved data and the phone upgrade journey.

**Evidence boundary:** added rows are source/resource observations, not executed runtime proof. Every witness below is **planned / unexecuted here**; existing test sources are anchors, not results.
